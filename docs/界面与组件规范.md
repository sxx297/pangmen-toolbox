# 旁门工具箱界面与组件规范

版本：1.0，2026-09-15。覆盖形状效果、动画库、PDF 导出和关于窗口，后续界面修改继续沿用。

## 实现来源

- `shared/ui/tokens.json`：设计数值和颜色的唯一来源。
- `shared/ui/components.css`：WebView 公用组件、模块语义选择器和窄屏适配。
- `tools/build-theme.py`：生成 Web CSS 与 `host/ToolboxTheme.cs`。构建自动执行，预览可单独执行。
- WinForms 关于窗口与悬浮外壳使用 `ToolboxTheme`；系统标题栏遵循 Windows / Office 的 DPI 与字体设置。

## 字体层级

采用 Microsoft YaHei UI，Web 回退 Segoe UI、sans-serif。尺寸为 96 DPI 下的逻辑像素，系统 DPI 放大后不手工叠加第二次缩放。

数值动画的缩略图和动态预览使用 `number-font`：Bahnschrift、600 字重、等宽数字，回退 DIN Alternate / Arial；它是预览画面字体，不改变文稿中原有数字的字体。

数值缩略图的静止状态也通过同一数字渲染器绘制终帧，使用相同字号、固定数字格、行高和居中方式。不能在静止时退回普通字符串排版，避免悬停播放和移出时整组数字的字距、位置跳变。

| 用途 | 字号 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 面板内容主标题 | 20 | 600 | 主文字 |
| 当前动画效果名称 | 16 | 600 | 主文字 |
| 参数分组、卡片标题 | 14 | 600 | 主文字 |
| 标签、按钮、分段切换、正文 | 12 | 400；选中 500 | 主文字或次文字 |
| 说明、单位、紧凑底栏 | 11 | 400 | 辅助文字 |

说明行高 1.6，标题 1.4。不要将 9px / 10px 用作关键操作文字。画布中的 PPT 内容和动画示例有独立排版，不被宿主主题重写。

## 颜色层级

| 角色 | 色值 | 用途 |

| 品牌强调 | `#ff5500` | 主按钮、选中、焦点反馈 |
| 强调悬停 / 浅底 | `#e94d00` / `#fff1e8` | 主按钮悬停、轻强调 |

| 主文字 | `#302b27` | 标题与正文 |

## 公共组件

### 双项分段切换

“元素动画 / 文本动画”“弥散渐变 / 液态玻璃”及预设库类型共用一套规范：总高 38px，底槽圆角 10px，内边距 3px、间隔 4px；按钮高 32px、圆角 8px、左右内边距 8px、字号 12px。选中使用暖白底、细边和浅阴影，橙色字；未选中使用次文字。颜色、背景与阴影过渡 170ms，减少动态效果模式关闭过渡。使用真实按钮与 `aria-selected` 或 `aria-pressed`。

### 输入、底栏与提示

- 普通控件最小高度 32px、圆角 8px。形状与动画底栏控件共用 36px 高度（`footer-control-height`），下拉框与操作按钮一致。4 / 8 / 12 / 16 / 24px 间距优先。
- 染色、底色及高光颜色共用 24 × 24px 色块，保持圆角与键盘焦点提示。
- 保存、复制和重命名预设弹窗使用紧凑布局：宽度最多 320px，内边距 20px，内容间隔 16px，14px 标题、32px 输入框；空错误提示不占位，操作按钮右对齐，焦点使用橙色细线。
- 动画侧栏底部三项保持一行：替换动画（或保留动画）、单击时 / 同时开始 / 之后开始、预览动画（更新时为更新并预览）。缩短文字而不改变执行语义；可访问名称保留用途。
- Toast 固定于内容区顶部居中（顶部 112px），避开顶部切换和分类导航。宽度最多 440px，左右至少 16px；深色实底、白字、12px 字号、行高 1.6，长句换行，不抢焦点、不拦截按钮。保留 `role=status` 与实时朗读。
- 错误详细信息可留在模块状态区；不能只通过颜色表示失败。

### 滚动条与滑杆

- 滚动条命中宽 10px，透明边距各 3px，可见宽 4px，圆角、最小长 28px；无箭头。
- 常态 / 悬停 / 拖动颜色为 `#d7d3cd` / `#b6aea5` / `#9f978e`。Chromium 不并用 `scrollbar-width:thin`。
- 形状、动画与 PDF 的滚动区域都由共享根选择器覆盖，确保模块原有的 `thin` 和颜色规则不会重新启用系统箭头。
- 形状与动画参数滑杆统一：4px 轨道，12px 圆形滑块、暖白边、灰色填充，焦点有橙色轮廓。

### 布局、悬浮窗和弹窗

- 形状与动画悬浮窗默认 1000 × 1040 逻辑像素，宽度比 1.0.0 缩小约 22%。按屏幕可用空间收缩、居中；同一文稿的两个模块同步手动调整的尺寸。
- 动画库每次新会话默认侧栏；会话中切换模式后保留状态。
- 预设库在 280–480px 的窄视口保持双列，缩略图保持比例，名称允许省略并提供完整 title，操作不能挤出卡片。
- 预设库名称使用 `library-label` 10px；置顶与更多图标相邻、独立命中，常态无色底，置顶状态以橙色图标表示。“使用预设”按钮比卡片内容窄 12px、高度 28px、顶部间距 4px，属于紧凑卡片内的控件例外。
- 快捷预览图使用 5px 圆角并填满画布显示框，避免等比留白使实际图片边缘仍呈直角。
- 快捷预设名称最多显示四个字，不加省略号；内置名称使用四字以内短名（如“珍珠柔雾”），自定义名称超过四字时仅缩短快捷标签，悬停提示、可访问名称和预设库保留完整名称。侧栏使用 `preset-label` 专用字号 9px / 12px 行高，保持单行显示；这是一处明确的字体例外，不扩散到操作按钮和参数标签。
- 快捷预设选中态只在缩略图外围画 1px 橙色细框，向外留 2px，不围住文字或整张按钮。侧栏缩略图与名称间隔 6px、卡片间距 6px，按钮内容高 58px，不预留第二行名称高度；名称用较轻的小字。键盘焦点仍有完整可见轮廓，避免将选中态和焦点混淆。
- PDF 保留较大的多页选择窗口及响应式网格，字体、配色、菜单、焦点和滚动条使用共享主题。
- 关于窗口保留“旁”字 Logo、官网与 AI 工作台卡片；采用同一字体和颜色层级。不得在产品 About 界面堆放构建路径、测试日志或 Git 哈希。

## 验收

使用 280、300、320、390、480px 侧栏，以及 1000px 悬浮窗验证：分段高度和字号一致、底栏单行、预设双列、长提示可读、无横向溢出。保留键盘焦点和减少动态效果支持。Office 标题栏、原生文件对话框由系统绘制，不能承诺其像素外观与网页完全一致。

- 预览画面左上角的状态提示使用 10px 辅助字、4 × 7px 内边距。
- 动画时长范围 0.2–8 秒、动作幅度 10%–300%；预览与 PowerPoint 端保持一致。
- 关于排版：640 × 350 逻辑像素内容区、28px 外边距、56px Logo、20px 品牌标题；两张等宽卡片高192px，正文14/12px，链接在内容下方。原生绘制按实际布局缩放，不依赖 Office 宿主中可能不准确的 DeviceDpi。

- 参数滑杆悬停/键盘焦点：橙色滑块与4px浅橙光圈；拖动时扩大至5px，过渡180ms；减少动态效果时关闭过渡。形状、动画、PDF同类滑杆统一。
- 动画时长、幅度、错峰间隔支持直接输入；与滑杆双向同步，输入时允许临时留空，失焦恢复有效值或限制至边界。单位留在输入框旁，明确秒与百分比。

### 操作提示组件实现

形状与动画统一调用 `shared/ui/toast.js` 的 `PangToast`；CSS 统一定义在 `components.css`。提示自动换行、高度随内容增长、不设内部滚动条、不截断文字。形状提示挂在模块根节点，不随参数区滚动或模式切换被裁切。普通提示停留1.8–3.5秒（随长度增长），错误2.8–5秒；后一次消息替换前一次计时，保留完整文本朗读。画布内的“正在读取背景”属于独立状态标记，继续使用紧凑样式。

### 参数数值框

动画时长、幅度、间隔、角度与形状参数统一64 × 26px、6px圆角、浅灰底。单位包含在同一个容器内，焦点使用容器整体1px橙色边框与2px浅橙光圈；内部输入不另画轮廓。焦点不改变尺寸，键盘输入仍有清晰状态。尺寸由 `parameter-*` 设计变量统一提供。

### 方向选择按钮

运动/揭示方向、翻转轴向、旋转支点、旋转方向统一使用44 × 44px图标按钮、8px圆角、6px间距。选中态使用浅橙底、橙色边框与内描边，键盘焦点共用同一层橙色边框，不额外增加外轮廓；所有状态保持尺寸不变。位置方向用箭头，翻转用同一SVG双向箭头旋转90°以保证视觉尺寸一致，支点用矩形与角点示意，旋转用弧形箭头；标题旁保留当前选项文字，图标提供可访问名称与悬停说明。自由角度保留可拖动指针，外框与其他方向按钮一致。样式集中在共享组件中，尺寸来自 `direction-*` 变量。


## 1.0.7 补充约束

- 原生宿主共用`PanelLoadingView`：相同暖白背景、品牌标记和“正在加载…”。遮罩在WebView创建前位于最前方，收到初始状态、字体和两帧布局完成后的就绪消息才撤下。
- 两模块的双项分段切换只绘制一块170ms滑动底板，按钮不再重复绘制背景或阴影；鼠标点击无外框，键盘焦点保留内侧轮廓，减少动态效果时禁用过渡。
- 无选区打开形状插件只保留画布提示。停靠面板“选择一个形状”按12 CSS px渲染，悬浮面板保持原尺寸。
- 停靠底栏按钮固定36px；统一12px底部间距，消除形状页面额外的底部外边距。动画底栏三列宽度1:1:1.22。
- 悬停未选中动画卡片只播放缩略图，不重播右侧选中动画；悬停已选中卡片可重播已完成的右侧动画。点击卡片切换并正常播放。

## 1.0.8 补充约束

- 公共加载层使用正式透明圆角品牌图片，不以字体字符替代 Logo。标记56px，品牌标题沿用14px分组字号，说明沿用12px正文字号，底部72 × 3px细进度条；整体居中，按DPI统一缩放。隐藏及释放时停止绘制定时器，错误状态保留完整信息。
- 可见的右侧预览不因窗口短暂失焦而暂停。失焦只清理缩略图悬停播放；用户暂停、时间轴定位、页面隐藏、停靠侧栏以及原生幻灯片预览继续按明确动作暂停，不在焦点返回时强制恢复。
