## 动画库

### 基本流程

1. 在 PowerPoint 中选中对象；多对象动画应先同时选中多个对象。
2. 打开“旁门工具箱 → 动画库”，选择“元素动画”或“文本动画”。
3. 在进入、强调、循环、退出分类中选择动画卡片。点击卡片会切换预览并按当前设置应用；当前选区不可用时会提示。
4. 调整时长、方向等当前效果支持的参数。无作用的参数不会显示。
5. 选择“替换动画”或“保留动画”，设置单击时、同时开始或之后开始；使用底栏“预览动画 / 更新并预览”查看 PowerPoint 放映结果。

**右侧预览的含义：** 展示当前选中的效果；悬停其他卡片只播放该卡片缩略图，不改变右侧选择。浏览器示例用于选型，最终以 PowerPoint 放映为准。

### 参数说明

| 控件 | 含义 |
| --- | --- |
| 动画时长 | 单个效果的时长，范围 0.2–8 秒；逐字或多对象效果还会受间隔影响 |
| 动作幅度 | 位移、缩放等动作的强弱，仅对有效的效果显示 |
| 方向、翻转轴向、旋转支点 | 依据具体动画选择方向或支点；不是所有效果都有这些选项 |
| 间隔 | 逐字/多对象的错开时间；支持的效果提供该参数 |
| 尘雾 | 轰然坠落的落点尘雾开关 |
| 替换 / 保留 | 替换选中对象已有动画，或保留后追加；修改前建议保存文稿 |

### 案例一：轰然坠落

适合标题、图形或产品卡片的重点登场。选中对象后，在“元素动画 → 进入”中选择“轰然坠落”，先使用 1.8 秒和默认幅度，再根据版面调整。给落点两侧留出空间，便于看清尘雾。

![轰然坠落](media/anvil.gif)

示例中的尘雾通过辅助对象与时序实现。后续替换或更新请使用插件流程，避免手动删除不认识的辅助对象而破坏动画。

### 案例二：数字滚动与数值变动

“数值滚动”表现逐位滚轮；“数值变动”表现固定位置的数值递增。两者均读取原文本框中的目标值，可用于 `128,640`、`¥1,280.50`、`86.5%` 等单一数值。

![数字滚动](media/number-roll.gif)

每次选择 **一个单行数字文本框**。文本框须无旋转、无填充、无边框，字体、字号、粗斜体和颜色一致。

| 检查项 | 当前支持范围 | 超限处理 |
| --- | --- | --- |
| 数值 | 绝对值 ≤ 999,999,999 | 提示缩小数值或使用“万 / 亿”等单位 |
| 小数 | 最多 6 位 | 提示减少小数位 |
| 文本长度 | 数字、符号、单位合计最多 40 个字符 | 提示缩短文本 |
| 字号 | ≤ 180 磅；文本必须单行 | 提示单行与字号要求 |
| 实际文本宽度 | ≤ 1,400 pt | 属于当前渲染范围限制，建议缩小字号或缩短内容 |
| 格式 | 全部字符格式统一 | 提示统一字体、字号与文字颜色 |
| 内容 | 一个数值，可有前后符号/单位 | 多组数字或段落不会作为一个数值处理 |

例如 `2026 年营收 128,640` 包含两组数字，应将说明和数值分成两个文本框。保留原来的数字文本供后续编辑，播放过程使用透明辅助图像，不应手动拆散这些对象。

## 形状效果

### 弥散渐变

1. 插入或选中支持的可填充形状，打开“形状效果”。
2. 选择“弥散渐变”，从预设开始。
3. 调整底色、整体色光强度；展开效果图层，分别调整颜色、位置、大小、模糊、不透明度和混合模式。
4. 点击“应用到选中形状”。完成后可保存为个人预设，也可导出 PNG。

![弥散渐变案例](media/gradient.png)

**使用建议：** 保持文字和材质形状分开，方便独立排版与改字。用少量低对比色光做背景，把高亮留给轮廓或重点区域。当前最多 16 个效果图层。

### 液态玻璃

1. 先完成背景，再选中叠放在背景上的形状。
2. 进入“液态玻璃”，选择清透、雾面或带颜色的玻璃预设。
3. 用折射强度、背景模糊、厚度和边缘高光控制质感。
4. 应用到选中形状；背景内容或位置发生变化时，重新“刷新背景”并应用。

![液态玻璃案例](media/glass.png)

玻璃采样当前背景生成图像，不会在 PowerPoint 放映中持续实时计算折射。背景上有颜色、纹理或线条时，变化更容易观察。

### 恢复、保存与支持边界

- **恢复原样**：通过插件恢复保存的原始对象；不要自行删除用于恢复的辅助对象。
- **保存预设**：保存材质参数，方便后续复用；预设不等于完整幻灯片模板。
- **导出 PNG**：导出材质图像，可用于其他页面；不要把渲染图像误认为完全可编辑的矢量材质。
- 部分旋转、翻转、组合对象及导入图片受限制。SVG/AI 导入内容是否可用取决于 PowerPoint 实际识别出的形状类型与轮廓；必要时先转为可编辑的单个形状。
- 读取轮廓失败时，插件会保留草稿并停止应用。重新选择目标或刷新背景后重试，不应把失败当作已应用成功。

## PDF 导出

选择需要的页面，再选择“体积优先”“均衡”“画质优先”或自定义。自定义分辨率支持 72–600 DPI，实际还受大画布像素上限保护。导出后打开检查页序、清晰度与完整性。

输出是 **图片型 PDF**，适合保留页面视觉版式；需要可搜索文字、可选中文本或无障碍标签的场景，请另选符合该用途的导出方式。

## 常见问题

**为什么点击卡片后 PPT 中也有动画？**

卡片选择参与当前应用流程，并非完全隔离的素材浏览。操作前选对对象；已有动画需要保留时，先选择“保留动画”。

**为什么看不到动作幅度或方向？**

控件按当前动画的实际能力显示。参数缺席通常表示该效果不使用它。

**修改了背景，玻璃为什么没有自动变化？**

材质基于捕获的背景生成，背景改变后需要刷新并重新应用。

**安装后没有看到选项卡？**

先关闭并重新打开 PowerPoint；确认 WebView2 Runtime 与 .NET Framework 4.8 已安装。可使用开始菜单的修复入口。如仍失败，提交插件版本、Office 位数和脱敏后的诊断，不要关闭系统安全防护来尝试解决。

**支持 WPS、Mac 或网页版吗？**

当前面向 Windows 桌面版 Microsoft PowerPoint，没有承诺其他平台兼容。
